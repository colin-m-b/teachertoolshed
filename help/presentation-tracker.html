Presentation Tracker

What it is for, the first task, and the things that go wrong. Every screenshot and video uses the sample class — no real student appears anywhere.

What it is for

The Presentation Tracker is a scoring sheet for a day of presentations. You set up the running order — individuals, or groups you assign by tapping names — attach a rubric, and set a time limit per presentation. While each group presents you score the rubric once for the group, and override any criterion for one member whose contribution was clearly different, so a group grade stays honest without a second rubric. A timer counts the presentation; feedback boxes hold what you'd say aloud. At the end, the summary lays out every group and every student with totals, and prints. Rubrics are shared with the Talk Tracker, so one MYP rubric serves both.

The first task

  1. Name the session and load a class. Choose Individual or Groups; for groups, add the group names, then tap students to put them in the active group. Auto-split fills groups evenly if you don't care who is with whom.
  2. Attach a rubric from the dropdown, or make one: a criterion name, an optional description, and a score range. Leave the range blank for a comment-only criterion.
  3. Set a time limit and press Start Session. For each group: start the timer, score the criteria, add group feedback, and open a member's card to override a score or add individual feedback. Next moves along the running order.
  4. Press End Session in the header. The summary shows every group, every member and every total; Print gives you a paper record. The session is saved under Past Sessions.

Things that go wrong

A student isn't in the running order.
In group mode a student who wasn't assigned to a group or marked “presenting solo” is left out; the tool warns before starting. Go back and assign them.
I scored the group, but one member did nothing.
Open that member's card under the group and set their score for the criterion. The override shows as such on the summary and in the CSV.
The timer didn't start on its own.
It never does — presentations begin when you say so. Press Start when the group starts talking.
Where did last week's session go?
Free shows the latest saved session; older ones are kept and come back with Pro, along with Student History: each student's totals across every session.
I want the same rubric in the Talk Tracker.
It is already there. Saved rubrics are one shared list.
