Talk Tracker

What it is for, the first task, and the things that go wrong. Every screenshot and video uses the sample class — no real student appears anywhere.

What it is for

The Talk Tracker turns a seminar, debate or discussion into a record. Set up the session, start it, and the class appears as a grid of names; tap a name each time that student contributes. A tag on the tap says what kind of contribution it was, a note button holds anything you noticed, a timer runs in the sidebar, and talking points can be ticked off as the class reaches them. End the session and you get a summary: who spoke how often against the target you set, which topics were covered, rubric scores if you attached one, and a print view. The point is to leave a discussion with evidence rather than an impression — and to notice, from the summary, who never spoke.

The first task

  1. Name the session, pick a saved class from the dropdown (or paste names), and set a target — three contributions per student is a sensible default.
  2. Optionally add talking points: the questions or ideas you want the discussion to reach.
  3. Press Start Session. Start the timer if you want a duration recorded. Tap a name when that student speaks; long-press or use the tag popup for the kind of contribution; the corner button on each card takes a private note.
  4. Press End Session. The summary shows the bars, the talking points covered, and a notes box per student. Press Print for a paper copy. The session is saved automatically and reappears under Past Sessions next time.

Things that go wrong

I refreshed mid-discussion and lost the tally.
You didn't — the live session is autosaved every few seconds. Reopen the tool and it picks up where you left off.
A student tapped twice by mistake.
Right-click (or long-press) a card to take one contribution off.
My names came in as one long line.
Paste one name per line, or comma-separated on a single line. A mix of both confuses it.
I can only see my most recent session.
Free shows the latest saved session; the earlier ones are kept, are in every backup, and reappear with Pro. Pro also adds the term report: one row per student across every session.
The rubric scores aren't on the summary.
A rubric is scored after the session, on the summary screen, not live. If no rubric card appears, none was attached at setup.
