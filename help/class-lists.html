Class Lists

What it is for, the first task, and the things that go wrong. Every screenshot and video uses the sample class — no real student appears anywhere.

What it is for

Class Lists is where every other tool gets its students. You build a class once — paste names from anywhere, or import the CSV your school system exports — and the Talk Tracker, Presentation Tracker, Seating Chart Maker and Stack Splitter all offer it from a dropdown. It is also the backup point: Export writes one JSON file holding every class list and everything saved in every tool, and Import reads it back on this or another device. Nothing here is sent anywhere. The lists live in this browser's own storage, which is why the backup matters. If you buy Pro, this is also where the licence key goes.

The first task

  1. Open Class Lists and press Load a sample class. Twenty-four invented students appear, tagged “Sample”, so you can try every tool before typing a real name.
  2. Press + New, give the class a name, and paste the students in — one per line, or straight from a spreadsheet with ID numbers in a second column. The preview under the box shows how the paste was read; fix the column roles if it guessed wrong.
  3. Press Save class list. Open the Talk Tracker in another tab: the class is already in its “Saved classes” dropdown.
  4. Come back and press Export under Backup. Keep that file somewhere safe; it is the only copy that exists outside this browser.

Things that go wrong

My class list vanished.
Browser storage was cleared — by you, by a district policy, or (on Safari) by a week of not visiting. Import your last backup. On Chrome, Edge and Firefox the page asks the browser to keep this site's storage; Safari ignores that, so export after any big change.
The paste put ID numbers where names should be.
Under the box, each column has a small dropdown: set the one holding numbers to ID and the other to Name. Tick “First row is a header” if your spreadsheet's column titles came along.
Two students have the same name.
Give them ID numbers. The tools key everything off an internal id, so two students with the same name and no ID become one student in the Talk Tracker's tallies.
The list is on my laptop but not my classroom PC.
Storage is per browser, per device. Export on one, Import on the other. Pro will add sync through your own Google Drive or OneDrive so this happens by itself.
I can't add a third class.
Free keeps two class lists on a device (the sample never counts). Delete one, or see the Pro page. Nothing is deleted when a limit is hit.
