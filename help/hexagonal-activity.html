Hexagonal Activity Creator

What it is for, the first task, and the things that go wrong. Every screenshot and video uses the sample class — no real student appears anywhere.

What it is for

Hexagonal thinking gives students a set of terms on hexagons and asks them to arrange them so that touching edges mean something — then to justify the connections. The Creator makes the digital version: you type terms into colour groups (characters, themes, quotations, whatever fits), press Create, and get a link. Every student who opens the link gets their own canvas with the same hexagons, drags them into a shape, and exports the result as an image for their notebook or your feedback. The activity is encoded in the link itself, so there is no server, no account and nothing for a student to sign into; a class of thirty can work from one line in Google Classroom.

The first task

  1. Add a group, give it a name and a colour, and type terms one per line. Add another group for a second kind of term. The preview shows the hexagons as they will appear.
  2. Press Create & Get Link. Copy the link and post it where your class will find it.
  3. Open the link yourself to see the student view: drag hexagons from the tray, snap them edge to edge, and press Export for a PNG.
  4. To reuse the activity, press Save under Saved Activities. With Pro, Print hexagon sheet gives a paper version to cut out.

Things that go wrong

The link is enormous.
That's the activity inside the link. It's meant to be pasted, not read aloud. A shortener works if you need one.
A student's canvas reset.
Each browser keeps its own canvas for that link. A different device, a cleared browser or a private window starts fresh — export before leaving.
Students can see each other's work.
They can't. Every canvas is independent and nothing is shared between them; if you want to compare, have them export and hand in the image.
There's a limit on hexagons?
No. Add as many terms as the activity needs.
I can only save one activity.
Free keeps one saved activity on a device; the share link always works regardless. Pro keeps a library.
